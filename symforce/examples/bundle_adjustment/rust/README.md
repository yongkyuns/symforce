# Rust + stack-algebra bundle adjustment

This is the Rust port of the runtime-sized bundle-adjustment example. It uses the same C++
configuration: seed `42`, two views, twenty inverse-range landmarks, the same priors, pixel
matches, weights, calibration, factor ordering, and optimizer parameters.

The dataset in `src/dataset.rs` was exported from the C++ `BuildValues` implementation. The
symbolic pose-prior, inverse-range-prior, and reprojection residuals and Jacobians are generated by
`generate_rust.py` with the stack-algebra backend. The camera calibration uses the typed
`symforce_rust::LinearCameraCal` runtime type, matching the native C++ factor's
`LinearCameraCal` boundary.

Run it with:

```sh
cargo run --manifest-path symforce/examples/bundle_adjustment/rust/Cargo.toml
```

The Rust result matches the C++ reference to the displayed precision:

```text
final error: 4.199758157939
pose 1: (0.465621612626, 0.249793074451, -0.838783404595, 0.131310068116,
         0.907417266878, -1.446180523440, -0.847274613067)
```
