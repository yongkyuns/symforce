# Rust 2D localization

This is the fixed-size pure-Rust version of the SymForce 2D localization
example. The shared factor residuals, Jacobians, Gauss–Newton Hessians, and right-hand
sides are generated by SymForce using the `stack-algebra` Rust target.
The numerical dataset is generated from the same Python `build_initial_values`
source used by the C++ example, and the reported error is the half sum of
squares used by SymForce's C++ optimizer.

From the SymForce repository root:

```bash
python symforce/examples/robot_2d_localization/generate_rust.py
cargo run --manifest-path symforce/examples/robot_2d_localization/rust/Cargo.toml
```

The Cargo project pins the compatible `stack-algebra` fork revision and the repository's
unified `rust/symforce` crate.
